# Changelog

## 1.1.0 — 2026-09-13

Наведение порядка во всём репозитории.

### Структура
- Одна реализация на калькулятор: `calcpro-wpf`, `calcpro-glass`, `ios-calculator`.
- Удалены WinUI-порты обоих Electron-калькуляторов: они отставали по функциям,
  а у iOS-порта был баг с разделителями тысяч. Удалены также архивы (`calc-payload.7z`,
  `files.zip`), готовый `.exe` в дереве, HTML-прототип, обходные скрипты для
  electron-builder (`7za_wrapper.cs`, `extract_wincodesign.py`), логи и служебные папки.
  Всё это доступно в коммите `3c8fb43`.
- Общий `build.ps1`: тесты, portable и setup для всех трёх.
- Убраны декоративные пузыри на фоне (WPF и Glass): остался только градиентный фон.
- Исправлено обрезание кнопок в стандартном размере окна: в WPF нижний ряд уходил
  за край панели (кнопки больше не держат жёсткую высоту, окно 780×720), в Glass
  скругление окна срезало углы крайних кнопок (отступы клавиатуры увеличены).

### Calc Pro (WPF)
- Движок вынесен в библиотеку `CalcPro.Core` без зависимости от WPF.
- Исправлено: скобки не работали. `( 2 + 3 ) =` давало Error, потому что после `)`
  к выражению приклеивался `0`. Добавлены неявное умножение `(2+3)4`, автозакрытие
  скобок на `=`, функция после `)` применяется к группе: `(9+7) √` = 4.
- Исправлено: после `=` константа, функция, вставка из истории или буфера оставляли
  в выражении хвост `" ="`, и следующий оператор давал мусор.
- Исправлено: `±` после `=` терялся при продолжении вычисления.
- Исправлено: undo не восстанавливал «пустой» `LastResult`.
- Исправлено: `exp(100)`, `99999999999999^9`, `asin(2)` роняли приложение
  (`OverflowException` / `(decimal)NaN`). Теперь это ошибка на дисплее.
- Исправлено: `tan(90)` возвращал 1.6e16 вместо ошибки.
- `%` теперь постфикс (`200 × 10 %` = 20), а не бинарный оператор, ломавший выражение.
- Приоритет `!` и `%` поднят выше `^`: `2^3!` = 64, как принято в математике (было 40320).
- Защита от переполнения стека: глубина вложенности ≤ 256, длина ≤ 1000 токенов.
- Portable-сборка сжата (single-file compression).

### Calc Pro Glass (Electron)
- Логика вынесена из 2400-строчного HTML в `calc-core.js` (движок) и `app.js` (DOM).
  Поведение сверено со старым кодом differential-тестом на 3000 случайных
  последовательностей нажатий.
- Исправлено: `-2^2` давало 4, теперь −4 (унарный минус слабее `^`).
- Исправлено: `+/-` на пустом экране открывал `neg(`, который съедал весь дальнейший
  ввод (`+/- 3 + 5 =` давало −8). Теперь `+/-` переключает знак операнда.
- Повреждённая история в localStorage больше не ломает запуск.
- Electron 33 → 43, CSP, sandbox, продукт переименован в «Calc Pro Glass»,
  чтобы не путать с WPF-версией. `appId` прежний, установщик обновит старую установку.

### Calculator iOS 26 (Electron)
- Логика вынесена в `calc-engine.js`, сверена со старым кодом differential-тестом.
- Безопасность: `nodeIntegration: true` / `contextIsolation: false` заменены на preload
  с `contextBridge` и sandbox. У страницы больше нет доступа к Node.js.
- Исправлено: очень большие и маленькие числа (`1e-7`) неверно читались обратно,
  и `5 + mr(1e-7) =` давало −2.
- Исправлено: деление на ноль посреди цепочки показывало `Ошибка + `.
- Исправлено: π, `mr` и `Rand` на свежем экране давали `03,14…`.
- Electron 33 → 43, CSP, DevTools только при запуске из исходников.
