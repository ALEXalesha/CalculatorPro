# Контекст разработки калькулятора Apple iOS 26

## Что было сделано

Создавали HTML/CSS/JS калькулятор - точную копию приложения Calculator из iOS 26 в стиле Liquid Glass. Прошли через несколько итераций.

## Итоговый стек

- Один файл `calculator.html` со встроенными CSS и JS
- Без внешних зависимостей
- Liquid Glass: `backdrop-filter: blur(30px) saturate(180%)`, тонкие inset-блики, цветной размытый фон под "стеклом"

## Архитектура логики (после рефакторинга)

Логика построена на референсе предыдущего pygame-калькулятора Алексея. Принцип "два поля":

- **Белое поле снизу**: `currentExpr` - накапливает выражение по мере ввода: `2`, потом `2 + `, потом `2 + 3`
- **Серое поле сверху**: `lastExpression` - заполняется только при `=` или цепочке операций

Состояния:
- `currentExpr` - текущее видимое выражение
- `lastExpression` - то что показывается серым
- `firstOperand` - первый операнд (число)
- `pendingOperator` - текущий оператор (`+`, `-`, `*`, `/`, `^`)
- `isInputtingNew` - флаг "только что был оператор, ждём новое число"
- `isResultShown` - флаг "показан результат после ="

Ключевые функции:
- `getLastNumber()` - извлекает последнее число из `currentExpr` regex'ом `(-?[\d,]+)$`
- `replaceLastNumber(newNum)` - заменяет последнее число
- `endsWithOperator()` - проверка что выражение заканчивается на ` op `

## Поведение

- `2 + 3 =` → белое `5`, серое `2 + 3 =`
- `2 + 3 *` → белое `5 × ` (промежуточный результат), серое `2 + 3`
- `2 + 3 * 4 =` → белое `20`, серое `5 × 4 =`
- `1 + 2 = + 3 =` → продолжение с результата, итог `6`
- Замена оператора: `5 + -` → `5 − ` (последний переписывается)
- `±` после оператора: `5 + ` → `±` → `5 + -0` → `3` → `5 + -3`
- C: первое нажатие сбрасывает только текущее число до `0`, второе - всё (AC)
- `%`: `100 + 20%` готовит `100 + 20` (20 = 100 × 20 / 100), `=` даёт `120`

## Дизайн

**Liquid Glass кнопки:**
```css
backdrop-filter: blur(30px) saturate(180%);
background: rgba(60, 60, 67, 0.45);
border: 0.5px solid rgba(255,255,255,0.18);
box-shadow:
  inset 0 1px 0 rgba(255,255,255,0.18),
  inset 0 -1px 0 rgba(0,0,0,0.15),
  0 1px 2px rgba(0,0,0,0.2);
```

**Цветной фон под стеклом** - SVG с радиальными градиентами (розовый, голубой, оранжевый, фиолетовый) на тёмно-фиолетовой подложке `#1a0a2e`.

**Раскладка iOS 26 базовая (4×5):**
- Ряд 1: `⌫ AC % ÷` (новая раскладка iOS 26, не `AC ± %`)
- Ряд 2-4: цифры + операторы
- Ряд 5: `+/− 0 , =` (нижняя кнопка `0` НЕ растянутая)

**Научный режим:**
- Открывается через меню (•••) или плашку "Научные функции"
- 25 функций: `sinh cosh mc m+ m-`, `2nd x² x³ xʸ eˣ`, `10ˣ 1/x ²√x ³√x ln`, `log₁₀ x! sin cos tan`, `Rad π e Rand mr`
- 2nd переключает sin/cos/tan на arcsin/arccos/arctan, sinh/cosh на arsinh/arcosh

## Что было исправлено по ходу

1. **Не помещалось при открытии научных** - результат наезжал на заголовок. Уменьшил шрифты, кнопки, отступы. Запас по высоте 16px.
2. **Логика была через парсер выражений** - переписали под пошаговую логику pygame.
3. **Знак появлялся слева** - был `direction: rtl` для скролла, разворачивал визуальный порядок. Убрал, заменил на `text-align: right` с `scrollLeft = scrollWidth`.
4. **C не сбрасывал полностью** - повторное нажатие теперь делает полный сброс.
5. **± после оператора не работал** - теперь добавляет `-0` как затравку.
