# Промт для Claude Code

Привет, Claude. Мне нужно превратить мой HTML-калькулятор (точная копия Calculator iOS 26) в полноценное Windows-приложение с установщиком NSIS.

## Что есть на входе

В рабочей папке:
- `calculator.html` - готовый калькулятор, всё в одном файле (HTML + встроенные CSS и JS), без внешних зависимостей
- `icon.ico` - иконка для exe (содержит размеры 16, 32, 48, 64, 128, 256)
- `icon.png` - иконка 1024×1024 для установщика
- `CONTEXT.md` - контекст разработки калькулятора (для понимания логики если понадобится)

## Что нужно сделать

### 1. Обернуть HTML в десктопное приложение

Используй **Electron** (последняя стабильная версия). Создай минимальную Electron-обёртку:

**Главное окно:**
- Размер по умолчанию: 420×860 (пропорция iOS-устройства)
- **Минимальный размер: 320×640** - чтобы не сжимался слишком сильно
- **Окно полностью масштабируется** - resize-able, без фиксированных размеров
- **Без верхней панели/меню** - `frame: false`, `titleBarStyle: 'hidden'`
- **Без статус-бара (времени, иконок) в самом HTML** - в HTML сейчас есть `.notch`, `.status-bar`, `.home-bar` внутри `.phone` - все эти элементы НУЖНО УДАЛИТЬ из HTML или скрыть через CSS-инъекцию в Electron
- **Скруглённые края окна** - используй `transparent: true` + CSS `border-radius` на body или контейнере. Радиус ~24px
- **Окно можно перетаскивать** - сделай область заголовка калькулятора (где надпись "Калькулятор" и кнопка •••) draggable через CSS `-webkit-app-region: drag`, а кнопки внутри `-webkit-app-region: no-drag`

**Адаптация HTML:**
- Удали элементы `.notch`, `.status-bar`, `.home-bar` (они нужны были только для мокапа iPhone)
- Убери `.phone` контейнер с фиксированной шириной 390px и высотой 844px - калькулятор должен растягиваться на всё окно
- Цветной градиентный фон оставь - он часть Liquid Glass дизайна
- Кнопки **должны масштабироваться пропорционально размеру окна** - используй `aspect-ratio: 1` на `.btn` чтобы они оставались круглыми, а не сжимались по Y
- Сейчас кнопки имеют `height: 64px` (фикс) - переделай на flex/grid с `aspect-ratio: 1` или используй `min(vw, vh)`-based размеры

**КРИТИЧНО:** кнопки сейчас при открытии научного режима сжимаются по Y и становятся овальными. Это нужно исправить - они должны оставаться круглыми всегда. Сделай так чтобы при нехватке места уменьшался размер шрифта и кнопок пропорционально, но не пропорция.

**Подход к адаптивности:**
1. Контейнер калькулятора занимает 100% окна
2. Кнопки в grid'е, каждая `aspect-ratio: 1`
3. Размеры шрифтов через `clamp()` или CSS-переменные, привязанные к `min(100vw, 100vh)`
4. При узком окне всё уменьшается пропорционально

**Кнопка закрытия:** добавь в правый верхний угол маленькую кнопку × для закрытия окна (раз нет нативной рамки). Стиль - в духе Liquid Glass.

**Кнопка свернуть:** аналогично, в левом верхнем углу или рядом с ×.

### 2. Структура Electron-проекта

```
calculator-app/
├── package.json
├── main.js              # точка входа Electron
├── preload.js           # (если нужен)
├── renderer/
│   ├── index.html       # адаптированный calculator.html
│   └── window-controls.js  # логика кнопок свернуть/закрыть
├── assets/
│   ├── icon.ico
│   └── icon.png
└── build/               # сюда соберётся exe
```

`main.js` должен:
- Создать BrowserWindow с параметрами выше
- Загрузить `renderer/index.html`
- Обрабатывать IPC от кнопок свернуть/закрыть
- Не показывать меню (`Menu.setApplicationMenu(null)`)

### 3. Сборка exe и NSIS-установщика

Используй **electron-builder** с конфигурацией для NSIS. В `package.json` секция `build`:

```json
{
  "appId": "com.alexeystepnov.calculator",
  "productName": "Calculator iOS 26",
  "win": {
    "target": "nsis",
    "icon": "assets/icon.ico"
  },
  "nsis": {
    "oneClick": false,
    "allowToChangeInstallationDirectory": true,
    "createDesktopShortcut": true,
    "createStartMenuShortcut": true,
    "shortcutName": "Calculator",
    "installerIcon": "assets/icon.ico",
    "uninstallerIcon": "assets/icon.ico",
    "installerHeaderIcon": "assets/icon.ico",
    "deleteAppDataOnUninstall": true
  }
}
```

Скрипты:
```json
"scripts": {
  "start": "electron .",
  "build": "electron-builder --win nsis"
}
```

### 4. Что должно получиться на выходе

- `Calculator-Setup-1.0.0.exe` в папке `build/` - установщик NSIS
- При установке: можно выбрать папку, создаются ярлыки на рабочем столе и в меню Пуск
- При запуске: окно калькулятора со скруглёнными углами, без рамки, полностью масштабируется, кнопки остаются круглыми

## Важные моменты

- **НЕ ЛОМАЙ ЛОГИКУ КАЛЬКУЛЯТОРА** - вся JS-логика в `<script>` блоке должна остаться нетронутой. Меняем только HTML-структуру обёртки и CSS под адаптивность.
- **Сохрани Liquid Glass эстетику** - градиентный фон, blur на кнопках, тонкие границы.
- **Кнопки должны быть КРУГЛЫМИ** в любом размере окна. Если они овалятся - значит CSS адаптивности написан неправильно.
- Если столкнёшься с тем что `backdrop-filter` не работает на `transparent: true` окне - используй `backgroundMaterial: 'acrylic'` или просто непрозрачный градиентный фон без transparency окна (тогда `transparent: false`, но скругление через CSS на body всё равно сделает закруглённые углы видимыми за счёт отрисовки).
- Если хочешь, можно вообще не делать `transparent: true`, а просто задать `frame: false` и нарисовать скруглённые углы через CSS - современные Windows 11 уже поддерживают это нативно через DWM.
